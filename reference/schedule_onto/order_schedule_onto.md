# 订单计算本体

## 1 概念

| 概念        | 含义                                           |
| ----------- | ---------------------------------------------- |
| 订单        | 客户销售订单或询单，包含订单头信息             |
| 订单明细    | 订单的具体行项，记录需要交付的货品、数量和交期 |
| 货品        | 企业生产输出的物料，包含成品和半成品、         |
| BOM基本信息 | 生产该货品所需的物料清单                       |
| 排产任务    | 根据订单创建的生产排程任务                     |
| 排产结果    | 排产任务执行后产出的调度方案及关键指标         |
| 欠料明细    | 下发排产结果与当前库存对比后得出的缺料清单     |
| 算法参数    | 排产任务的优化目标参数，定义排产策略和约束     |

## 2 关系

| 源概念   | 关系名               | 目标概念    | 基数 | 说明                                                      |
| -------- | -------------------- | ----------- | ---- | --------------------------------------------------------- |
| 订单     | hasDetail            | 订单明细    | 1:N  | 1个订单含多个明细项                                       |
| 订单明细 | hasProduct           | 货品        | N:1  | 1个订单明细只包含1个货品，1个货品可以指向多个订单明细     |
| 货品     | hasBOM               | BOM基本信息 | 1:1  | 1个货品有1个BOM，1个BOM基本信息对应1个货品                |
| 订单     | drivesScheduling     | 排产任务    | 1:N  | 1个订单可以产生多个排产任务                               |
| 排产任务 | hasVersionDerivative | 排产任务    | 1:N  | 1个排产任务可衍生多个版本或场景排产任务，表示版本派生关系 |
| 排产任务 | producesPlan         | 排产结果    | 1:1  | 1个排产任务产出1个排产结果                                |
| 排产结果 | hasShortageDetail    | 欠料明细    | 1:N  | 1个排产结果对应多个原料欠料明细                           |
| 排产任务 | hasScheduleParams    | 算法参数    | 1:1  | 1个排产任务有1组算法参数                                  |

## 5 规则

### 5.1 验证规则

| 编号 | 规则名                  | 规则描述                                                                           | 涉及概念           |
| ---- | ----------------------- | ---------------------------------------------------------------------------------- | ------------------ |
| V01  | 订单创建-订单类型       | 订单明细.类型 只能是询单或销售二选一                                               | 订单               |
| V02  | 订单明细-货品存在性     | 订单明细.货品编号和货品名称 必须存在于 货品                                        | 订单明细、货品     |
| V03  | 订单明细-截止日期约束   | 订单明细.截止日期 > 订单明细.起排日期                                              | 订单明细           |
| V04  | 订单明细-交付数量约束   | 订单明细.交付数量 > 0                                                              | 订单明细           |
| V05  | 订单明细-优先级约束     | 订单明细.优先级 只能是按期交付或可延期交付                                         | 订单明细           |
| V06  | 订单更新-未排产约束     | 订单更新时，该订单必须未创建排产任务，否则拒绝                                     | 订单、排产任务     |
| V07  | 订单删除-未排产约束     | 订单删除时，该订单必须未创建排产任务，否则拒绝                                     | 订单、排产任务     |
| V08  | 创建排产任务-唯一性约束 | 创建排产任务时，该订单只能创建一次排产任务                                         | 订单、排产任务     |
| V09  | 新增排产任务-状态约束   | 新增排产任务时，传入的scheduleId对应排产任务状态需为已排产                         | 排产任务           |
| V10  | 启动排产任务-状态约束   | 启动排产任务时，scheduleId还未开启排产                                             | 排产任务、算法参数 |
| V11  | 启动定时查询-状态约束   | 启动排产结果定时查询时，该scheduleId对应的排产任务刚启动，状态不是已完成或数据错误 | 排产任务           |
| V12  | 排产结果下发-状态约束   | 排产结果下发时，该scheduleId对应的排产任务为已排产，且方案状态为未锁定             | 排产任务、排产结果 |
| V13  | 排产结果撤回-状态约束   | 排产结果撤回时，该scheduleId对应的排产任务为已排产，且方案状态为已下发             | 排产任务、排产结果 |

| ---- | -------------------------------------------- | ------------------------------------------------------------------------------------------------------------ | ---------------------------- |
| I01  | 已排产完成后可新增排产任务                   | 排产任务.任务状态 = "已排产" → 可以此排产任务为基础新增场景任务，可调整算法参数后重新计算                   | 排产任务、排产结果           |
| I02  | 排产结果成功下发后提示查欠料                 | 排产结果.方案状态 = "已下发" → 提示用户或智能体查询该排产结果的欠料明细                                     | 排产结果、欠料明细           |
| I03  | 欠料查出后提示创建采购单                     | 欠料明细查询到，且该订单未关联采购单或关联采购单不满足欠料需求 → 提示用户或智能体是否创建原材料采购单       | 订单、欠料明细、原材料采购单 |
| I04  | 订单创建后提示排产                           | 订单创建成功 → 提示用户或智能体可对该订单创建排产任务                                                       | 订单、排产任务               |
| I05  | 排产任务创建或新增排产任务后提示创建算法参数 | 排产任务创建成功 → 提示用户或智能体可创建算法参数                                                           | 排产任务，算法参数           |
| I06  | 排产启动后提示等待                           | 排产任务启动 → 提示用户或智能体需等待结果，已自动启动定时任务轮询；也可主动发起查询排产结果和排产任务状态； | 排产任务、排产结果           |
| I07  | 排产结果撤回后提示撤采购                     | 排产结果撤回 → 若已有采购记录，提示用户或智能体是否撤回相关采购申请                                         | 排产结果、采购单             |
| I08  | 算法参数创建后提示启动                       | 算法参数创建成功 → 提示用户或智能体可启动该排产任务                                                         | 算法参数、排产任务           |
