# 资源本体

## 1 概念

| 概念         | 含义                                                             |
| ------------ | ---------------------------------------------------------------- |
| 设备         | 生产加工用的机器或产线                                           |
| 设备组       | 同类型或同工作中心的设备集合                                     |
| 人员         | 参与生产的操作工或技术工                                         |
| 人员组       | 同技能或同工种的人员集合                                         |
| 部门         | 企业组织架构单元，包含生产部门和非生产部门                       |
| 资源日历     | 设备或人员的工作日历，定义时间范围内的作息和休假规则，含班次信息 |
| 班次         | 每日工作时间段，含开始时间、结束时间和休息时段                   |
| 设备异常记录 | 设备在指定时间段内的异常停机记录                                 |

## 2 关系

| 源概念   | 关系名         | 目标概念     | 基数 | 说明                                            |
| -------- | -------------- | ------------ | ---- | ----------------------------------------------- |
| 设备     | belongsToGroup | 设备组       | N:1  | 1台设备只属于1个设备组，1个设备组含多台设备     |
| 设备     | belongsToDept  | 部门         | N:1  | 1台设备只属于1个部门                            |
| 人员     | belongsToGroup | 人员组       | N:1  | 1个人员只属于1个人员组，1个人员组含多人员       |
| 人员     | belongsToDept  | 部门         | N:1  | 1个人员只属于1个部门                            |
| 资源日历 | containsShift  | 班次         | N:1  | 1个日历只包含1个班次；1个班次可以属于多个日历； |
| 设备     | hasDowntime    | 设备异常记录 | 1:N  | 1台设备可有多条异常记录                         |
| 设备     | hasCalendar    | 资源日历     | N:1  | 多台设备最多可关联1个资源日历                   |
| 人员     | hasCalendar    | 资源日历     | N:1  | 多个人员最多可关联1个资源日历                   |

## 5 规则

### 5.1 验证规则

| 编号 | 规则名                  | 规则描述                                  | 涉及概念             |
| ---- | ----------------------- | ----------------------------------------- | -------------------- |
| V01  | 资源日历-结束时间合理性 | 资源日历.结束时间 > 资源日历.开始时间     | 资源日历             |
| V02  | 班次-结束时间合理性     | 班次.结束时间 > 班次.开始时间             | 班次                 |
| V03  | 资源日历-班次存在性     | 资源日历.班次名称 必须存在于 班次         | 资源日历、班次       |
| V04  | 资源日历-资源存在性     | 资源日历.资源名称 必须存在于 设备 或 人员 | 资源日历、设备、人员 |

### 5.2 推理规则

| 编号 | 规则名                  | 规则描述                                                                                                                      | 涉及概念                     |
| ---- | ----------------------- | ----------------------------------------------------------------------------------------------------------------------------- | ---------------------------- |
| I01  | 可用时长/产能的计算引导 | 计算设备或人员的可用时长/产能时，先提取该资源关联班次的起止时间，接着获取其资源日历的有效起止日期，最后分析其设备异常记录情况 | 资源日历、班次、设备异常记录 |
