# 货品本体

## 1 概念

| 概念               | 含义                                        |
| ------------------ | ------------------------------------------- |
| 货品               | 企业生产输出的物料，包含成品和半成品        |
| 货品库存           | 货品当前的待入库、可用库存和累计库存        |
| BOM基本信息        | 物料清单基本信息                            |
| BOM明细            | BOM的组成项，记录子货品、用量及对应工艺路径 |
| BOM原材料需求      | BOM对每种原料总需求量                       |
| BOM设备组需求      | BOM对每个设备组需求                         |
| BOM人员组需求      | BOM对每个人员组需求                         |
| 工艺路径           | 货品的生产工艺路径基本信息                  |
| 工艺路径原料需求   | 工艺路径对原材料的需求                      |
| 工艺路径设备组需求 | 工艺路径对设备组的需求                      |
| 工艺路径人员组需求 | 工艺路径对人员组的需求                      |

## 2 关系

| 源概念      | 关系名              | 目标概念       | 基数 | 说明                                                          |
| ----------- | ------------------- | -------------- | ---- | ------------------------------------------------------------- |
| 货品        | hasProductInventory | 货品库存       | 1:1  | 每个货品对应一条库存快照                                      |
| 货品        | hasBOM              | BOM基本信息    | 1:1  | 1个货品有1个BOM，1个BOM对应1个货品                            |
| BOM基本信息 | hasBOMDetail        | BOM明细        | 1:N  | 1个BOM含多个BOM明细项                                         |
| BOM明细     | refersToProduct     | 货品           | N:1  | 1个BOM明细项有1个货品，1个货品可关联多个BOM明细               |
| BOM明细     | hasRoute            | 工艺路径       | N:1  | 1个BOM明细项对应1条工艺路径，1条工艺路径可被多个BOM明细项使用 |
| BOM基本信息 | requiresMaterial    | BOM原料需求    | 1:N  | 1个BOM可包含多个原料需求                                      |
| BOM基本信息 | requiresEquipGroup  | BOM设备组需求  | 1:N  | 1个BOM可包含多个设备组需求                                    |
| BOM基本信息 | requiresPersonGroup | BOM人员组需求  | 1:N  | 1个BOM可包含多个人组需求                                      |
| 工艺路径    | requiresMaterial    | 工艺原料需求   | 1:N  | 1条工艺路径可关联多个原料需求                                 |
| 工艺路径    | requiresEquipGroup  | 工艺设备组需求 | 1:N  | 1条工艺路径可关联多个设备组需求                               |
| 工艺路径    | requiresPersonGroup | 工艺人员组需求 | 1:N  | 1条工艺路径可关联多个人组需求                                 |
