# 原材料本体

## 1 概念

| 概念           | 含义                                                                                                            |
| -------------- | --------------------------------------------------------------------------------------------------------------- |
| 原材料         | 生产过程中消耗的外部输入物料，需采购和考虑库存                                                                  |
| 原材料库存     | 原材料当前的待入库、可用库存和累计库存                                                                          |
| 原材料采购记录 | 原材料的采购记录，关联供应商和客户订单；1个条采购记录只有1个原料，且只关联1个供应商；1条采购记录只关联1个订单； |
| 供应商         | 原材料的供应方                                                                                                  |
| 客户订单       | 客户的销售订单或询单，驱动原材料采购的源头                                                                      |

## 2 关系

| 源概念         | 关系名                 | 目标概念 | 基数 | 说明                                                    |
| -------------- | ---------------------- | -------- | ---- | ------------------------------------------------------- |
| 原材料         | hasRawInventory        | 库存     | 1:1  | 每个原材料对应一条库存快照                              |
| 原材料采购记录 | recordsRawMaterial     | 原材料   | N:1  | 1个原材料可有多个采购，1个采购记录只关联1个原材料       |
| 原材料采购记录 | orderedFromSupplier    | 供应商   | N:1  | 1个供应商可以对应多个采购单，1个采购单只有1个供应商     |
| 供应商         | suppliesRawMaterial    | 原材料   | N:M  | 1个供应商可供应多个原材料，1个原材料可来源多个供应商    |
| 客户订单       | containsPurchaseRecord | 采购记录 | 1:N  | 1个采购记录最多只关联1个订单，1个订单可关联多个采购记录 |

## 5 规则

### 5.1 验证规则

（SHACL，结构/格式/范围/约束，是否合规，数据质量保证）

| 编号 | 规则名              | 规则描述                                         | 涉及概念           |
| ---- | ------------------- | ------------------------------------------------ | ------------------ |
| V01  | 采购-原料单位一致性 | 采购记录.单位 必须等于 原材料.单位               | 采购记录、原材料   |
| V02  | 库存-原料单位一致性 | 库存.单位 必须等于 原材料.单位                   | 库存、原材料       |
| V03  | 到位时间合理性      | 到位时间 > 采购时间                              | 采购记录           |
| V04  | 采购-原料存在性     | 采购记录.原材料名称 必须存在于 原材料            | 采购记录、原材料   |
| V05  | 采购-供应商存在性   | 采购记录.供应商名称 必须存在于 供应商            | 采购记录、供应商   |
| V06  | 采购-订单存在性     | 采购记录.关联订单编号非空时，必须存在于 客户订单 | 采购记录、客户订单 |

### 5.2 推理规则

（SWRL，IF-THEN，归纳和演绎，及时做出响应 ）

| 编号 | 规则名           | 规则描述                                                                                           | 涉及概念           |
| ---- | ---------------- | -------------------------------------------------------------------------------------------------- | ------------------ |
| I01  | 安全库存预警     | 库存.可用库存量 < 原材料.安全库存，推送原材料采购或转库存预警；                                    | 库存、原材料       |
| I02  | 采购到位超期预警 | 当前日期 >= 采购记录.到位时间，提示用户是否启动入库操作                                            | 采购记录           |
| I03  | 采购目的推理     | 采购记录.关联订单编号为空 → 该采购为补充库存                                                      | 采购记录、客户订单 |
| I04  | 采购关联订单校验 | 采购记录.关联订单编号不在客户订单表中 → 提示用户该客户订单可能已取消/删除，请确认是否取消该采购单 | 采购记录、客户订单 |
