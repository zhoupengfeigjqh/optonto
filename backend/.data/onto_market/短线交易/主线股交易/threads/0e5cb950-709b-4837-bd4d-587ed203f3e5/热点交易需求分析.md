## 阶段0：领域聚焦与术语采集

### 领域聚焦
**基于游资行为模式的A股短线交易决策与风险控制**

### 业务术语表

| 英文名 (name) | 中文名 (display_name) | 详细描述 |
| :--- | :--- | :--- |
| HotSector | 热点板块 | 当前市场资金高度关注、持续上涨、涨停个股集中的行业或概念板块。是游资操作的核心战场。 |
| DragonStock | 龙头股 | 在热点板块中，涨幅最大、涨停最早、封板最坚决、对板块有引领作用的股票。是游资追逐的核心标的。 |
| MarketSentiment | 市场情绪 | 市场参与者（特别是游资）的集体心理状态，表现为恐慌、低迷、温和、升温、高潮、退潮等。 |
| SentimentTurningPoint | 情绪拐点 | 市场情绪从“升温”转向“降温”或从“降温”转向“升温”的关键节点，由政策、消息、盘面数据（如炸板潮）触发。 |
| PositionManagement | 仓位管理 | 根据市场环境（情绪、主线清晰度）和个股状态，动态调整投入资金比例的策略，核心是风险控制。 |
| RiskRule | 风险规则 | 一系列预定义的、用于规避系统性风险（如政策调控、市场退潮）和个股风险（如交易监管、炸板）的操作规则。 |
| 1-to-2Trade | 1进2交易 | 一种具体的短线交易模式，指买入首板涨停后，博弈其次日（二板）继续涨停的股票。 |
| CashFlowRotation | 资金轮动 | 资金从一个热点板块流出，流入另一个有预期差的板块的过程。是判断“承接分流资金板块”的基础。 |
| LiveStock | 活口 | 在板块分歧日或退潮日，依然能强势涨停，维持板块热度的核心个股。通常是下一波行情的潜在龙头。 |
| BufferBuff | Buff叠加 | 一只股票同时具备多个上涨逻辑（如：属于热点板块+业绩预增+政策利好），使其上涨确定性更高。 |
| RegulatoryWarning | 交易监管 | 交易所对异常交易行为（如涨幅过大、频繁交易）的股票发出的警示或限制，游资会主动规避此类股票。 |

> **修订说明**：
> 1. **删除** `Divergence`（分歧）和 `Consensus`（一致），改为 `Stock` 的属性 `timingStatus`。
> 2. **删除** `MarketSentiment` 独立概念，其枚举值（恐慌、低迷等）作为 `MarketState` 的属性 `sentimentLevel`。
> 3. **统一名称**：`RiskControlRule` 改为 `RiskRule`。

## 阶段1：系统性分析

### 1. 业务对象
- **核心对象**：市场（`Market`）、热点板块（`HotSector`）、股票（`Stock`）、市场状态（`MarketState`）、交易决策（`TradingDecision`）。
- **动作对象**：交易信号、交易决策。
- **辅助对象**：风险规则（`RiskRule`）、市场事件（`MarketEvent`）。

### 2. 业务语义（概念-属性-关系的粒度）
- **概念粒度**：新增 `Market` 概念，代表整个A股市场，与 `MarketState` 建立关系。
- **属性粒度**：`Stock` 新增 `timingStatus` 属性（枚举：分歧, 一致, 分歧转一致, 其他），替代独立的 `Divergence` 和 `Consensus` 概念。
- **关系粒度**：`MarketState` 是 `Market` 的状态描述，通过关系 `hasState` 连接。

### 3. 业务功能（行为与规则）
- **核心行为**：同原始版本，但新增规则优先级机制。
- **核心规则**：`AvoidHighChaoSector` 优先级高于 `StructureAdjustFocus`，避免逻辑互斥。

### 4. 主要业务流程
- 同原始版本。

### 5. 重要事件
- `SectorLimitUpSurge` 和 `SectorCollectiveLimitDown` 明确关联行为。

### 6. 安全与权限
- 同原始版本。

## 阶段4：业务流程确认

### 流程1：每日盘前策略生成流程

| 基本信息 | 内容 |
| :--- | :--- |
| **英文名称** | PreMarketStrategyGeneration |
| **中文名称** | 每日盘前策略生成流程 |
| **流程目标** | 在市场开盘前，基于昨日收盘数据和最新信息，生成当日的初步交易策略（选股、择时、仓位）。 |
| **流程描述** | 该流程在每日开盘前执行一次。首先识别当前市场的主线板块，然后在主线板块内筛选出强势股，接着对候选强势股进行时机评估，并结合市场状态计算建议仓位，最后综合所有信息生成初步的交易决策列表。 |

| 编号 | 当前动作 | 上一动作 | 步骤描述 | 衔接类型 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | IdentifyMainSector | (开始) | 分析所有热点板块数据，动态识别出当前市场的主线板块。 | 串行 |
| 2 | SelectStrongStock | IdentifyMainSector | 基于识别出的主线板块ID，在该板块内筛选出最强的个股（龙头或活口）。 | 串行 |
| 3 | AssessTiming | SelectStrongStock | 对上一步筛选出的每一只强股，评估其当前所处的时机状态（分歧/一致/分歧转一致/其他），判断是否为合适的买点。 | 并行 |
| 4 | CalculatePosition | AssessTiming | 结合当前市场状态（情绪、风险等级）和对个股的评估，计算建议的仓位比例。 | 串行 |
| 5 | CheckRisk | CalculatePosition | 对生成的候选决策，逐一进行风险规则检查（如避开监管票、高潮期限制等），按优先级处理规则冲突。 | 串行 |
| 6 | GenerateDecision | CheckRisk | 综合所有信息，为通过风险检查的候选股票生成正式的“买入”或“持仓”交易决策。 | 串行 |
